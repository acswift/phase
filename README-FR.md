# Color maps de Phase

Les color maps de Phase sont des LUT ([Look-Up Tables](https://aftershoot.com/blog/lut/), ou tables de correspondance).

Une LUT remplace simplement la couleur d’origine de chaque pixel par une nouvelle couleur, prise dans une table de nouvelles valeurs.

Selon l’écart entre les nouvelles valeurs et les anciennes, une LUT peut avoir un effet subtil ou spectaculaire.

Il existe plusieurs formats de fichiers pour les LUT — Phase utilise les fichiers `.cube`.

> Voir aussi [créer votre propre color map](instructions-fr.md)

---
### Color maps disponibles

Les images PNG ci-dessous contiennent un fichier `.cube` intégré.

Pour en ajouter une à Phase :
- appuyez longuement sur une image ci-dessous et choisissez « Copier »
- appuyez longuement dans les réglages de Phase et choisissez « Autoriser le collage »

> Vous pouvez changer le mode de fusion dans les réglages de Phase pour créer différents effets.
