# Phase Color Maps

Phase color maps are LUTs ([Look-Up Tables](https://aftershoot.com/blog/lut/)).

A LUT simply replaces the original color of each pixel with a new color from a (look-up) table of new values.

Depending on how far away the new values are from the old values, a LUT can have a subtle or dramatic effect.

There are several file formats used for LUTs — Phase uses `.cube` files.

> See also [create your own color map](instructions.md)

---
### Available Color Maps:

The PNG images below contain an embedded `.cube` file.

To add one of them to Phase:
- long-press an image below and select "Copy"
- long-press in Phase settings and select "Allow Paste"

> You can change the blending mode in Phase settings to create different effects.
